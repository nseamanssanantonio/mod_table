# Mod Table

Mod Table is a wavetable editor I've been working on. The idea is to have a way to build custom wavetables from scratch, with more control over the individual waveforms and how they interact.

It's not a synthesizer. It's meant to create wavetables that can be exported and used in other synths.

### Features

- Stack up to 64 waveforms with individual controls.
- Combine waves using FM, phase modulation, arithmetic, spectral processing, and other relationships.
- Apply up to 16 modifiers.
- Create up to 256 keyframes with different morphing and interpolation methods.
- Preview individual waves or the complete wavetable.
- Apply filtering and resonance across the finished table.
- Export WAV files with 128–8192 samples per frame.
- Optional high-quality rendering with additional oversampling and analysis.
- Automatic peak normalization on export.
- Save and reload projects.

### Development

This is still a work in progress. I'm continuing to improve the interface, rendering quality, and waveform processing. Some of the more experimental features will probably change as I work through them.
The goal is to make something that's fairly easy to use for simple wavetables but has enough options to create some really unusual ones.
